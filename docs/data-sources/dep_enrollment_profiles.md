# microsoft365wp_dep_enrollment_profiles (Data Source)

The enrollmentProfile resource represents a collection of configurations which must be provided pre-enrollment to enable enrolling certain devices whose identities have been pre-staged. Pre-staged device identities are assigned to this type of profile to apply the profile's configurations at enrollment of the corresponding device. <br/> Also see [Microsoft docs for enrollmentProfile](https://learn.microsoft.com/en-us/graph/api/resources/intune-enrollment-enrollmentprofile?view=graph-rest-beta).

_Provider_ Note: Classic Apple Automated Device Enrollment (DEP) enrollment profiles (iOS/iPadOS and macOS) of an enrollment
program token. ADE enrollment policies (settings catalog) are managed with
`microsoft365wp_device_management_configuration_policy` instead.

Updates always send the complete profile to MS Graph (all attributes, using their default values if they are
not set), as MS Graph resets the Setup Assistant settings of a profile (skip flags, `enabled_skip_keys` and
`itunes_pairing_mode`) when an update does not contain them.

To make a profile the default profile of its enrollment program token, use
`microsoft365wp_dep_default_enrollment_profile`.

The state of a `msgraph_resource` (provider `microsoft/msgraph`) with the url
`deviceManagement/depOnboardingSettings/<id>/enrollmentProfiles` can be moved to this resource with a `moved`
block (see the example).
