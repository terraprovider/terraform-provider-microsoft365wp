# microsoft365wp_browser_site_lists (Data Source)

Represents an enterprise site list in a compliant cloud location that specifies sites to be opened in [Internet Explorer mode](https://learn.microsoft.com/en-us/deployedge/edge-ie-mode). The site list contains one or more [browserSite](https://learn.microsoft.com/en-us/graph/api/resources/browsersite?view=graph-rest-beta) and [browserSharedCookie](https://learn.microsoft.com/en-us/graph/api/resources/browsersharedcookie?view=graph-rest-beta) resources. <br/> Also see [Microsoft docs for browserSiteList](https://learn.microsoft.com/en-us/graph/api/resources/browsersitelist?view=graph-rest-beta).

_Provider_ Note: Manages a Microsoft Edge Internet Explorer mode site list (Enterprise Mode Site List) including its sites
and shared cookies, as found in the Microsoft 365 admin center under Settings > Org settings > Microsoft Edge
site lists.

MS Graph keeps changes to sites and shared cookies as pending changes until the list gets published. This
resource does not model that draft stage: each create and update writes the changed sites and shared cookies
and then publishes the whole list, so that the published list equals the configuration afterwards. Pending
changes made elsewhere (e.g. in the admin center) are treated as drift: they show up in the next plan (as
differences in `sites` or `shared_cookies`, or as `status` changing to `published`) and get reverted
before the list gets published.

To use a site list, assign it in the Microsoft Edge policy "Configure the Enterprise Mode Site List" (outside
of this resource). A list that is still in use should be unassigned before it gets destroyed.

All writes of this resource type are serialized, as MS Graph loses parallel writes to a site list. Each site
or shared cookie that changes takes a separate request (roughly 0.4 seconds each).

Required permissions: `BrowserSiteLists.ReadWrite.All` (`BrowserSiteLists.Read.All` suffices for plans and
data sources; the Global Reader role does not).
