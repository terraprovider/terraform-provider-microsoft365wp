# microsoft365wp_mobile_threat_defense_connector_microsoft_defender (Resource)

Entity which represents a connection to Mobile Threat Defense partner. <br/> Also see [Microsoft docs for mobileThreatDefenseConnector](https://learn.microsoft.com/en-us/graph/api/resources/intune-onboarding-mobilethreatdefenseconnector?view=graph-rest-beta).

_Provider_ Note: This resource only manages the settings of the connector for **Microsoft Defender for Endpoint** (which has
the fixed id `fc780465-2017-40d4-a0c5-307022471b92` in every tenant).  
The connector itself can neither be created nor deleted by this provider: It gets created (with default
settings) once the "Microsoft Intune connection" setting is turned on in the Microsoft Defender portal, and
reading, importing or creating this resource fails as long as the connector does not exist. Destroying this
resource only removes it from Terraform state and leaves the connector and its settings untouched.  
Turning the "Microsoft Intune connection" setting off again does not delete the connector, it keeps its
settings and can still be managed (as of 2026-10).
