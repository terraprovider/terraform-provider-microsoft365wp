# microsoft365wp_dep_default_enrollment_profile (Resource)

The enrollmentProfile resource represents a collection of configurations which must be provided pre-enrollment to enable enrolling certain devices whose identities have been pre-staged. Pre-staged device identities are assigned to this type of profile to apply the profile's configurations at enrollment of the corresponding device. <br/> Also see [Microsoft docs for enrollmentProfile](https://learn.microsoft.com/en-us/graph/api/resources/intune-enrollment-enrollmentprofile?view=graph-rest-beta).

_Provider_ Note: Makes an Apple Automated Device Enrollment (DEP) enrollment profile the default profile of its enrollment
program token for new devices. This works for classic enrollment profiles (`microsoft365wp_dep_enrollment_profile`)
and for ADE enrollment policies (settings catalog policies, which MS Graph also lists as enrollment profiles of
the token, with the id `ECV2_<dep_onboarding_setting_id>_<policy id>`).

Only one profile per platform can be the default profile. If another profile gets made the default profile
(e.g. in the Intune portal), the next plan shows `is_default` changing to `true` and the apply makes this
profile the default profile again. Therefore, do not use more than one of these resources per platform and
enrollment program token.

On destroy, the resource only gets removed from the Terraform state, as MS Graph cannot unset the default
profile (another profile has to be made the default profile instead).

## Example Usage

```terraform
terraform {
  required_providers {
    microsoft365wp = {
      source = "terraprovider/microsoft365wp"
    }
  }
}

/*
.env
export ARM_TENANT_ID='...'
export ARM_CLIENT_ID='...'
export ARM_CLIENT_SECRET='...'
*/


variable "dep_onboarding_setting_id" {
  description = "Id of the enrollment program token (deviceManagement/depOnboardingSettings)"
  type        = string
}


resource "microsoft365wp_dep_enrollment_profile" "ios" {
  dep_onboarding_setting_id = var.dep_onboarding_setting_id
  display_name              = "TF Test iOS/iPadOS"
  ios = {
    supervised_mode_enabled = true
  }
}

# Make the classic profile the default profile of the enrollment program token for new iOS/iPadOS devices.
resource "microsoft365wp_dep_default_enrollment_profile" "ios" {
  dep_onboarding_setting_id = var.dep_onboarding_setting_id
  id                        = microsoft365wp_dep_enrollment_profile.ios.id
}


# For an ADE enrollment policy (settings catalog), use the id under which MS Graph lists it as an enrollment profile
# of the token.
variable "ade_enrollment_policy_id" {
  description = "Id of a macOS ADE enrollment policy (deviceManagement/configurationPolicies)"
  type        = string
}

resource "microsoft365wp_dep_default_enrollment_profile" "macos" {
  dep_onboarding_setting_id = var.dep_onboarding_setting_id
  id                        = "ECV2_${var.dep_onboarding_setting_id}_${var.ade_enrollment_policy_id}"
}
```

## Schema

### Required

- `dep_onboarding_setting_id` (String)
- `id` (String) The GUID for the object  
_Provider_ Note: The id of the enrollment profile to make the default profile, e.g. the `id` of a `microsoft365wp_dep_enrollment_profile` or `ECV2_<dep_onboarding_setting_id>_<id of an ADE enrollment policy>` for an ADE enrollment policy (settings catalog).

### Read-Only

- `display_name` (String) Name of the profile
- `is_default` (Boolean) Whether the profile is the default profile of its enrollment program token. It is always planned as `true`, so that the profile gets made the default profile again if another profile has been made the default profile in the meantime.

## Import

Import is supported using an `import` block (or the `terraform import` command) with the values of `dep_onboarding_setting_id`, `id`, separated by slashes:

```terraform
import {
  to = microsoft365wp_dep_default_enrollment_profile.example
  id = "<dep_onboarding_setting_id>/<id>"
}
```

As the `id` of a profile contains the id of its enrollment program token, the plain `id` is also accepted, e.g. `id = "437dc82e-9725-45e1-8126-ab8dc7014b1d_6de29b1b-9b37-40f4-99b8-9d8a1217ebc6"` or `id = "ECV2_437dc82e-9725-45e1-8126-ab8dc7014b1d_0f9e8d7c-6b5a-4f3e-9d2c-1b0a9f8e7d6c"`.
