# microsoft365wp_ip_application_segment (Resource)

Represents the segment configurations that are allowed for an **on-premises nonweb application** published through Microsoft Entra application proxy and accessed via non-HTTP protocols. <br/> Also see [Microsoft docs for ipApplicationSegment](https://learn.microsoft.com/en-us/graph/api/resources/ipapplicationsegment?view=graph-rest-beta).

_Provider_ Note: To import this resource, an ID consisting of `application_id` and `id` being joined by a forward slash (`/`) must be used.
