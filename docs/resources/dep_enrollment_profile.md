# microsoft365wp_dep_enrollment_profile (Resource)

The enrollmentProfile resource represents a collection of configurations which must be provided pre-enrollment to enable enrolling certain devices whose identities have been pre-staged. Pre-staged device identities are assigned to this type of profile to apply the profile's configurations at enrollment of the corresponding device. <br/> Also see [Microsoft docs for enrollmentProfile](https://learn.microsoft.com/en-us/graph/api/resources/intune-enrollment-enrollmentprofile?view=graph-rest-beta).

_Provider_ Note: Classic Apple Automated Device Enrollment (DEP) enrollment profiles (iOS/iPadOS and macOS) of an enrollment
program token. ADE enrollment policies (settings catalog) are managed with
`microsoft365wp_device_management_configuration_policy` instead.

Updates always send the complete profile to MS Graph (all attributes, using their default values if they are
not set), as MS Graph resets the Setup Assistant settings of a profile (skip flags, `enabled_skip_keys` and
`itunes_pairing_mode`) when an update does not contain them.

To make a profile the default profile of its enrollment program token, use
`microsoft365wp_dep_default_enrollment_profile`.

The state of a `msgraph_resource` (provider `microsoft/msgraph`) with the url
`deviceManagement/depOnboardingSettings/<id>/enrollmentProfiles` can be moved to this resource with a `moved`
block (see the example).

## Example Usage

```terraform
terraform {
  required_providers {
    microsoft365wp = {
      source = "terraprovider/microsoft365wp"
    }
  }
}

/*
.env
export ARM_TENANT_ID='...'
export ARM_CLIENT_ID='...'
export ARM_CLIENT_SECRET='...'
*/


variable "dep_onboarding_setting_id" {
  description = "Id of the enrollment program token (deviceManagement/depOnboardingSettings)"
  type        = string
}


resource "microsoft365wp_dep_enrollment_profile" "ios" {
  dep_onboarding_setting_id = var.dep_onboarding_setting_id

  display_name                                               = "TF Test iOS/iPadOS"
  description                                                = "Corporate iOS/iPadOS devices"
  requires_user_authentication                               = true
  require_company_portal_on_setup_assistant_enrolled_devices = true

  ios = {
    supervised_mode_enabled  = true
    is_mandatory             = true
    profile_removal_disabled = true
    itunes_pairing_mode      = "allow"
    support_department       = "IT"
    support_phone_number     = "+49 89 1234567"

    # Setup Assistant screens to skip: set the *_disabled attributes and enabled_skip_keys consistently
    apple_id_disabled             = true
    privacy_pane_disabled         = true
    siri_disabled                 = true
    terms_and_conditions_disabled = true
    enabled_skip_keys             = ["AppleID", "Privacy", "Siri", "TOS", "Intelligence"]
  }
}

resource "microsoft365wp_dep_enrollment_profile" "macos" {
  dep_onboarding_setting_id = var.dep_onboarding_setting_id

  display_name                 = "TF Test macOS"
  requires_user_authentication = true

  macos = {
    supervised_mode_enabled  = true
    is_mandatory             = true
    profile_removal_disabled = true

    file_vault_disabled = true
    siri_disabled       = true
    enabled_skip_keys   = ["FileVault", "Siri"]

    admin_account_user_name = "ADM-LAPS"
    admin_account_full_name = "Intune LAPS Administrator"
    hide_admin_account      = true
    dep_profile_admin_account_password_rotation_setting = {
      auto_rotation_period_in_days = 30
    }
  }
}


# Migration from msgraph_resource (provider microsoft/msgraph) without recreating the profile (Terraform >= 1.8,
# OpenTofu >= 1.10): move the state of the old resource to the new one (the id and the id of the enrollment program
# token are taken from the old state, everything else is read from MS Graph). After the next apply, the moved block
# can be deleted.

moved {
  from = msgraph_resource.dep_enrollment_profile
  to   = microsoft365wp_dep_enrollment_profile.migrated
}

resource "microsoft365wp_dep_enrollment_profile" "migrated" {
  dep_onboarding_setting_id = var.dep_onboarding_setting_id
  display_name              = "iOS/iPadOS - Default"
  ios = {
    supervised_mode_enabled = true
  }
}
```

## Import

Import is supported using an `import` block (or the `terraform import` command) with the values of `dep_onboarding_setting_id`, `id`, separated by slashes:

```terraform
import {
  to = microsoft365wp_dep_enrollment_profile.example
  id = "<dep_onboarding_setting_id>/<id>"
}
```

As the `id` of a profile starts with the id of its enrollment program token, the plain `id` is also accepted, e.g. `id = "437dc82e-9725-45e1-8126-ab8dc7014b1d_6de29b1b-9b37-40f4-99b8-9d8a1217ebc6"`.
