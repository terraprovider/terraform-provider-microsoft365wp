# microsoft365wp_group_assigned_licenses (Resource)

Represents a Microsoft Entra group, which can be a Microsoft 365 group, a team in Microsoft Teams, or a security group.

For performance reasons, the [create](https://learn.microsoft.com/en-us/graph/api/group-post-groups?view=graph-rest-beta), [get](https://learn.microsoft.com/en-us/graph/api/group-get?view=graph-rest-beta), and [list](https://learn.microsoft.com/en-us/graph/api/group-list?view=graph-rest-beta) operations return only a subset of more commonly used properties by default. These _default_ properties are noted in the [Properties](#properties) section. To get any of the properties not returned by default, specify them in a `$select` OData query option.

Also see [Microsoft docs for group](https://learn.microsoft.com/en-us/graph/api/resources/group?view=graph-rest-beta).

_Provider_ Note: Manages the licenses directly assigned to a group (group-based licensing) as one unit. All changes to a group's licenses are written with a single call to MS Graph (`assignLicense`), which avoids lost assignments when several licenses of the same group are changed in one run. This resource uses the same permissions as `microsoft365wp_group_assigned_license`, but both resources should not be used for the same group.<br><br> Creating this resource does not fail if (some of) the licenses are already assigned to the group: the configured licenses are applied on top of the existing ones (and, if `authoritative` is `true`, other licenses are removed). Therefore there is no need to import existing assignments.<br><br> The id of this resource is the id of the group. It can also be used to import this resource; note that after an import all licenses currently assigned to the group are considered to be managed by this resource.<br><br> When this resource is destroyed and thereby removes the last licenses of the group, it waits 15 seconds, since MS Graph refuses to delete a group immediately after its last license has been removed.<br><br> Note: When changing `authoritative` from `false` to `true`, the plan does not show the licenses that will be removed from the group, as they have not been tracked in state before.<br><br> Note: MS Graph processes license assignments asynchronously. A plan that is run immediately after an apply might therefore still show differences for a couple of seconds. Also, MS Graph does not check for available units when licenses are assigned: if a license has no free units left, the group's members get errors for all licenses assigned by the group (see `licenseAssignmentStates` of the users), even though this resource shows the licenses as assigned.

## Example Usage

```terraform
terraform {
  required_providers {
    microsoft365wp = {
      source = "terraprovider/microsoft365wp"
    }
  }
}

/*
.env
export ARM_TENANT_ID='...'
export ARM_CLIENT_ID='...'
export ARM_CLIENT_SECRET='...'
*/


resource "microsoft365wp_group_assigned_licenses" "test" {
  group_id = "298fded6-b252-4166-a473-f405e935f58d"

  # authoritative = true # remove any other licenses directly assigned to the group

  assigned_licenses = [
    {
      sku_id = "00ed1723-1992-4384-b7ce-1c3bf01eedc7"
    },
    {
      sku_id         = "05e9a617-0261-4cee-bb44-138d3ef5d965"
      disabled_plans = ["a23b959c-7ce8-4e57-9140-b90eb88a9e97"] # SWAY
    },
  ]
}
```

_Provider_ Note: The licenses to assign to the group (written using `assignLicense`). If `authoritative` is `false`, licenses assigned to the group by other means are not shown here. <br> (see [below for nested schema](#nestedatt--assigned_licenses))
- `group_id` (String) _Provider_ Note: The id of the group to assign the licenses to.

### Optional

- `authoritative` (Boolean) The _provider_ default value is `false`.  
_Provider_ Note: If `true`, this resource manages all licenses directly assigned to the group, i.e. licenses not listed in `assigned_licenses` will be removed from the group. If `false` (the default), only the licenses listed in `assigned_licenses` (and those removed from it) are managed and any other licenses of the group are left untouched.

### Read-Only

- `id` (String) The unique identifier for the group. <br/> Returned by default. Key. Not nullable. Read-only. <br/> Supports `$filter` (`eq`, `ne`, `not`, `in`).
